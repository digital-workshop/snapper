# Snapper 1.1.0

## English

Snapper now speaks **English and German**. The interface follows your Windows display language: German for German, English for everything else. Nothing else changes, your workflow stays the same.

- New: English interface, chosen automatically.
- New: English README (German version: [README.de.md](../README.de.md)).
- Fix: updated screenshots in the README.

As before: download `Snapper.exe` below (about 140 MB, nothing to install). The `.exe` is not signed. If Windows shows "Windows protected your PC", click **More info** and then **Run anyway**. To update, close Snapper and overwrite the old `Snapper.exe`.

## Deutsch

Snapper spricht jetzt **Englisch und Deutsch**. Die Oberfläche folgt der Windows-Anzeigesprache: Deutsch für Deutsch, Englisch für alle anderen. Sonst ändert sich nichts, du arbeitest wie gewohnt.

- Neu: englische Oberfläche, wird automatisch gewählt.
- Neu: englisches README (deutsche Fassung: [README.de.md](../README.de.md)).
- Fix: aktualisierte Screenshots im README.

Wie gehabt: `Snapper.exe` unten herunterladen (ca. 140 MB, nichts zu installieren). Die `.exe` ist nicht signiert. Zeigt Windows „Der Computer wurde durch Windows geschützt“, auf **Weitere Informationen** und **Trotzdem ausführen** klicken. Zum Aktualisieren Snapper schließen und die alte `Snapper.exe` überschreiben.
