# Snapper 1.0.0

Der erste Release. Schneller Screenshot-Ausschnitt mit Editor für Windows. Ein Nachbau der Grundidee von Skitch.

## Das kann Snapper

- **Sofort startklar:** Programm starten, der Bildschirm friert ein, Bereich aufziehen. Die Auswahl ist in unter einer Sekunde da.
- **Pfeil im Skitch-Stil:** hinten spitz, vorne dick, wächst live beim Ziehen. Dazu vier weitere Stile: Gerade, Dick, Doppelt, Linie.
- **Text, Rechteck und Verpixeln.** Verpixeln ist nicht umkehrbar, auch für Namen und Passwörter.
- **6 Farben, 3 Dicken**, Rückgängig und Wiederholen.
- **Ziehen:** Die rote Lasche unter dem Fenster gibt das fertige Bild als Datei weiter. Festhalten und in Mail, Chat, Explorer oder Claude Code fallen lassen.
- **Kopieren** in die Zwischenablage und **Speichern** als PNG nach `Bilder\Screenshots`.
- **Mehrere Bildschirme** und Windows-Skalierung werden unterstützt. Der Ausschnitt ist pixelgenau.
- **Update-Meldung:** Gibt es eine neuere Version, zeigt Snapper oben den Knopf „Update verfügbar“.

## So startest du

1. `Snapper.exe` herunterladen. Sie bringt alles mit (ca. 140 MB), es muss nichts installiert werden.
2. Doppelklick, oder an die Taskleiste heften.

Tipp: Auf der Taskleiste angeheftet startet ein Klick sofort die Auswahl.

## Gut zu wissen

- Die `.exe` ist nicht signiert. Beim ersten Start zeigt Windows evtl. „Der Computer wurde durch Windows geschützt“. Dann auf **Weitere Informationen** und **Trotzdem ausführen** klicken.
- Nur Windows 10 und 11, 64 Bit.
- Pfeile und andere Zeichnungen lassen sich noch nicht nachträglich ändern. Fehler korrigierst du mit `Strg+Z`.

## Tastenkürzel

| Taste | Aktion |
| --- | --- |
| `A` `T` `R` `P` | Pfeil, Text, Rechteck, Verpixeln |
| `Strg+Z` / `Strg+Y` | Rückgängig / Wiederholen |
| `Strg+C` / `Strg+S` | Kopieren / Speichern |
| `Strg+N` | Neuer Ausschnitt |
| `Esc` | Editor schließen |

## Geplant

Pfeile und Objekte nachträglich verschieben und ändern, Stift, Radierer, Zuschneiden, globales Tastenkürzel, Fenster- und Vollbild-Auswahl, Weichzeichnen.
